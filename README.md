# Student Assignment Tracker 📚

Student Assignment Tracker is a simple and user-friendly web application that helps students manage their assignments efficiently.

## 🚀 Features

- 🔐 Sign Up and Sign In
- 💾 LocalStorage-based data storage
- 📊 Dashboard with assignment summary
- ➕ Add new assignments
- 📅 Set due dates
- ⚡ Set assignment priority
- ✅ Mark assignments as completed
- 🗑️ Delete assignments
- 🔎 Filter assignments:
  - All
  - Pending
  - Completed
  - Overdue
- 👤 Personalized student welcome message
- 📱 Responsive and user-friendly UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
